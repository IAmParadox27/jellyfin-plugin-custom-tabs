Tab order

Number the tabs in the order they should appear in the header, Jellyfin's own tabs included. Change a number or use the arrows. Use the switch at the start of a row to show or hide that tab; for a custom tab it is the same as its Enabled switch. Applies to the newer header layout, where libraries appear as tabs; in the classic layout custom tabs always come after Home and Favorites. Tabs set to Header icons (right) are ordered in the next list.

    Header icon order

    Number the icon buttons on the right of the header, Jellyfin's own (and other plugins') together with tabs set to Header icons (right). Jellyfin's icons are listed once you have opened the Jellyfin home page in this browser with this version of the plugin installed. The user menu (profile picture) is pinned to the right end, like the menu button on the left, and can't be moved. Use the switch at the start of a row to show or hide that icon.
